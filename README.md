# ServiceHub - Service Menu Website

## About the Project
ServiceHub is a responsive service menu website built using HTML, CSS, JavaScript, and JSON.

## Features
- Category tabs to filter services
- Search services by name or category
- Service cards with descriptions and prices
- Add to Cart button with quantity tracking
- Responsive design for mobile and desktop
- Services loaded dynamically from a JSON file

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON

## Project Files
- `index.html` - Website structure
- `style.css` - Website styling
- `script.js` - Search, filtering, and cart functionality
- `services.json` - Service data

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Make sure all project files are in the same folder.
